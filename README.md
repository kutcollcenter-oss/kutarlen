# Сайт для менеджеров — продукт с кабинетами

Node.js + Express, обычный JavaScript на страницах. Данные — `data/db.json`, аналитика — `data/events/*.jsonl`, фото — `uploads/`.

## Запуск

```bash
npm install
npm start
```

- Страница сервиса для менеджеров: http://localhost:3000
- Кабинет: http://localhost:3000/admin — первый вход владельца: логин `admin`, пароль из `ADMIN_PASSWORD` (или `admin`). **Сразу смените пароль** в «Профиль».
- Адрес сайта владельца печатается в консоли при запуске.

При первом запуске создаются демо-данные. Заменить демо-квартиры владельца: `node lib/seed.js --keep-settings`.

## Как устроен продукт

- **Владелец** в разделе «Менеджеры» создаёт менеджеру кабинет: логин, пароль (генерируется), срок оплаты, лимит квартир. Сообщение с доступами копируется одной кнопкой.
- **Менеджер** в своём кабинете добавляет квартиры, своё фото, логотип, WhatsApp, отзывы и смотрит свою аналитику. Чужие данные ему недоступны.
- **Адрес сайта менеджера** — просто имя латиницей: `/aydana`, `/arlen` (занято — `/aydana2`). Владелец может поменять адрес вручную; старый адрес продолжает работать и ведёт на новый. Квартира открывается только по адресу своего менеджера.
- **Вход менеджера в кабинет** — `/имя/admin` (логин подставляется сам) или `/admin`.
- **Оплата.** Когда «оплачено до» прошло или менеджер заблокирован, его сайт показывает «временно недоступен». Продление — «+1 мес» / «+3 мес».
- **Лимит квартир** по тарифу (0 — без ограничения). Когда лимит исчерпан, новые квартиры добавить и дублировать нельзя — менеджер видит объяснение и кнопку «Написать о расширении тарифа». Уже добавленные квартиры остаются на сайте, их можно менять и удалять. Если уменьшить лимит ниже текущего числа, квартиры не удаляются.
- **Сайт владельца** работает всегда: без срока оплаты и без лимита.
- **Новая ссылка** — отозвать старую. **Новый пароль** — старые входы менеджера сразу закрываются.
- **Главная домена** — страница сервиса с кнопкой «Подключиться» на WhatsApp владельца (или сайт выбранного менеджера).

## Аналитика в кабинете

Посетители, просмотры, заявки в WhatsApp, конверсия и сравнение с прошлым периодом; график по дням; воронка
«зашли → фильтр → открыли квартиру → считали рассрочку → написали»; источники (Instagram, WhatsApp, Telegram, TikTok…);
квартиры (просмотры, расчёты, заявки); где нажимают WhatsApp; устройства; часы активности.
Ссылки с метками `?src=instagram` и т. п. копируются в разделе «Аналитика».
Посетитель считается по анонимному id в браузере, личные данные не собираются.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `ADMIN_PASSWORD` | Начальный пароль владельца при первом запуске. Потом пароль меняется в кабинете |
| `PORT` | Порт (по умолчанию 3000) |

## Что есть

- **Два способа оплаты.** Рассрочка — цены в сомах. Наличные — цена в `$`. Валюты меняются в настройках.
- **Карта.** В квартиру вставляется ссылка Google Карт («Поделиться» → «Копировать ссылку»), сервер находит в ней точку, на странице квартиры показывается карта и кнопка «Открыть в Google Картах». Без ссылки карта строится по адресу.
- **Расчёт рассрочки.** Менеджер указывает цену за м², площадь, минимальный взнос и срок. Сайт считает сам:
  `Цена = Цена за м² × м²`, `Платёж в месяц = ⌈(Цена − Взнос) / Срок⌉`.
- **Страница квартиры.** Клиент может внести больше минимального взноса — платёж в месяц пересчитывается, сообщение в WhatsApp тоже.
- **Фильтр.** Вкладки «Новостройки» / «Вторичка». Ползунки «Готов внести сейчас», «Платёж в месяц до», цена, комнаты, площадь. Для каждой квартиры показываем, какой взнос нужен под выбранный платёж.
- **Статусов нет.** Квартира на сайте, пока в ней указана цена. Проданную квартиру удаляют в админке; её старая ссылка ведёт на похожие.
- **Нижнее меню** на телефоне и ноутбуке: Главная, Квартиры, Отзывы, WhatsApp.
- **Контакты:** WhatsApp, Instagram, офис (2ГИС).
- Аналитика (GA4, Яндекс Метрика, пиксель Meta), уведомления в Telegram о нажатиях WhatsApp, ежедневные копии базы в `data/backups/`.

Заменить демо-квартиры, сохранив настройки: `node lib/seed.js --keep-settings`.
